# traversal — API Exploration Plugin for Claude Code

Autonomous exploratory testing for REST APIs. Shows Claude an OpenAPI spec and it designs test cases, executes requests, and logs issues with reproducible curl commands.

## Import into a project

**Option A — copy the skills directory**
```bash
cp -r /path/to/traversal/.claude/agents/* .claude/agents/
```

**Option B — npm (once published)**
```bash
npm install --save-dev @traversal/api-explorer
```
Then add to your project's `.claude/settings.json`:
```json
{
  "plugins": ["@traversal/api-explorer"]
}
```

## Skills

| Skill | Invoke | What it does |
|---|---|---|
| `orchestrator` | `/orchestrator <spec> [base_url] [auth]` | Full exploration run — parses spec, spawns parallel explorer agents |
| `explorer` | Internal (spawned by orchestrator) | Explores a batch of endpoints, logs issues, tracks session memory |
| `design-charters` | `/design-charters` | Generate test charters for one endpoint |
| `analyze-response` | `/analyze-response` | Analyze a request/response pair for issues |
| `bootstrap-ledger` | `/bootstrap-ledger <spec> [base_url] [auth]` | Initialize test-ledger.json from spec |
| `auth-probe` | `/auth-probe` | Sweep all explored endpoints for auth/IDOR issues |
| `session` | `/session [subcommand]` | View and manage session-memory.json |
| `cleanup` | `/cleanup` | Delete resources created during testing |
| `replay-issue` | `/replay-issue <ISSUE-NNN>` | Re-run an issue's curl and compare to original |
| `coverage-report` | `/coverage-report` | Report on what's been explored and what was found |

## Typical workflow

```
# 1. Bootstrap the ledger from your spec
/bootstrap-ledger ./openapi.yaml https://api.example.com "Authorization: Bearer mytoken"

# 2. Run the full exploration
/orchestrator ./openapi.yaml https://api.example.com "Authorization: Bearer mytoken"

# 3. Check the report
/coverage-report
```

## Output files

All written to the current directory (your project root):

- **`test-ledger.json`** — tracks which endpoints have been explored and their status
- **`session-memory.json`** — auth context, created resource IDs, known IDs for IDOR testing
- **`issues.md`** — all found issues with severity, observation, and curl command to reproduce
- **`coverage-report.md`** — final summary report (generated by `/coverage-report`)

## Requirements

- Claude Code with access to `Bash`, `Read`, `Write`, `Edit`, and `Agent` tools
- `curl` available in the shell
- `python3` with `pyyaml` installed (only needed for YAML specs — JSON specs work without it)
- The API must be reachable from the machine running Claude Code
